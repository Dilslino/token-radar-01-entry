How the number is built

Implied value = TVL × category multiple × growth × maturity × breadth.

  • Category multiple. The median market-cap-to-TVL ratio of the protocols in the same category whose token already trades. Categories with fewer than three live comparables use the global median. Clamped to 0.05 – 3.00.
  • Growth. The seven-day TVL change, clamped to −50%…+100%, bends the value by 0.6 per point.
  • Maturity. 0.65 at listing, rising to 1.00 at three years. Unknown listing dates count as one year.
  • Breadth. +3% per extra chain, capped at four extra chains.

The same arithmetic scores every row. No protocol name is special-cased. The snapshot is a frozen DefiLlama fetch; the board is this entry's claim about worth, not a prediction that a token ships, or when.

How to read a farm plan

Each row carries six steps: a fresh wallet, one core position sized to the protocol's TVL, a weekly qualifying action, a hold window, a safe claim, and a log. Costs and times are estimates from the protocol's own record. Never pay to claim; claim only through links the protocol itself publishes.
